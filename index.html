Agent ID check

MintGuard uses Binance Agent ID as the minter's identity layer: it reads the Agent ID registry on BSC to confirm the wallet checking a mint actually owns the Agent ID it claims. A verified Agent ID is a reputation signal — a mismatch or no Agent ID is a warning, not a pass.

How it works

  1. On-chain facts. MintGuard reads the contract directly from BSC (bytecode, owner, supply, name/symbol) and checks whether its source is verified on Sourcify.
  2. Deterministic checks. A transparent rule engine scores the risk: unverified source, owner powers, dangerous functions.
  3. Hybrid AI analysis. The facts are analysed by Gemini — preferably on-device with Gemini Nano (Chrome Desktop 139+, fast and private), falling back to the cloud model when on-device is unavailable. No API key is shipped in the app; Firebase AI Logic handles the backend.

MintGuard is a risk-screening aid, not financial advice. Always do your own research before minting.
